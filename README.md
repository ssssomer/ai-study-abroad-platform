# AI Study Abroad Platform

An AI-powered end-to-end study abroad and career planning platform.

## MVP

The first milestone focuses on the planning stage before university applications:

- Student portfolio and onboarding
- Readiness assessment
- Strengths and gap analysis
- 12-month improvement roadmap
- Task tracking and progress
- Reassessment as the student's profile improves

## Planned lifecycle

Explore → Profile → Career Direction → Profile Building → English → Internships → University Planning → Application → Offer → Visa → Housing → Arrival → Career

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase
- OpenAI API
- Zod
- Vercel

## Local setup

1. Copy `.env.example` to `.env.local`.
2. Add Supabase and OpenAI credentials.
3. Install dependencies with `npm install`.
4. Start the app with `npm run dev`.
